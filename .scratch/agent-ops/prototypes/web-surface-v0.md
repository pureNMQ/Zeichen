# Web 功能面原型 v0(待审阅)

> 基于 01 数据模型、05 状态机、06 权限、07 文档形态、08 MCP 工具面(Web 是 MCP 的镜像面)。
> 信息架构:两级导航——工作区级(顶部)+ 项目级(左侧栏)。

## 信息架构总览

```
工作区(顶部导航)
├── 项目列表           ← 默认落地页;admin 见全部,member 见已加入
├── 成员管理(admin)    ← 人类成员
├── Agent 管理(admin)  ← 创建/授权/key/活动
└── 当前用户菜单(改密码/退出)

项目(进入项目后,左侧栏)
├── 需求
├── 任务
├── 文档
│   ├── Wiki
│   ├── 字典
│   └── API
├── 记忆
└── 项目设置(owner)
```

## 页面清单(带权限标注)

### 工作区级

| 页面 | 权限 | 内容 |
|---|---|---|
| 登录页 | 公开 | 邮箱+密码;首用户引导=注册(创建 admin) |
| 项目列表页 | 全部 | 卡片/列表展示项目,新建入口(admin) |
| 成员管理页 | admin | 成员列表/邀请(邮箱)/改角色/移除 |
| Agent 管理页 | admin | agent 列表;创建 agent(命名+选项目+角色);每 agent:授权调整、key 管理(签发/回看[密码验证]/吊销/多 key)、最近活动 |
| 用户菜单 | 本人 | 改密码、退出 |

### 项目级

| 页面 | 权限 | 内容 |
|---|---|---|
| 需求列表页 | viewer+ | 看板或列表视图,按状态过滤;创建入口(editor+) |
| 需求详情页 | viewer+ | 描述、状态、关联任务列表、引用面板(被谁引用/引用了谁)、评论流、活动流、状态操作(editor+):完成验收/取消/软删 |
| 任务列表页 | viewer+ | 看板视图(按状态列:待办/实现中/已完成/已取消)或列表;过滤:需求/指派者 |
| 任务详情页 | viewer+ | 描述、指派信息、认领/开始/完成/取消按钮(按权限)、评论流、活动流 |
| Wiki 列表页 | viewer+ | 页面列表(可按父页浏览) |
| Wiki 编辑页 | editor+ | IR 模式 Markdown 编辑器 + 版本历史/回滚 |
| Wiki 阅读页 | viewer+ | 渲染阅读 + 反向引用显示 |
| 字典页 | viewer+ | 词条列表(搜索/前缀过滤) |
| 字典词条页 | editor+ 编辑 | 词名/定义/别名 + 互引显示 |
| API 列表页 | viewer+ | API 定义列表 |
| API 详情页 | viewer+ | 自动渲染的结构化 schema(端点/参数/字段)+ Markdown 说明;editor+ 可编辑 |
| 记忆管理页 | viewer+? | 见下节 |
| 项目设置页 | owner | 项目改名/成员管理(加/踢/改角色)/删项目 |

## 记忆管理页(核心新页面,细化)

依赖 02 的隔离机制(dataset/agent_id 元数据)与 08 的 memory 工具面:

| 区块 | 内容 | 交互 |
|---|---|---|
| 项目级记忆总览 | 本项目相关记忆条数、消耗 token 概览 | 默认页 |
| 按 agent 过滤 | 选择某个 agent,看"它记住了什么" | 下拉选择(本项目有权 agent) |
| 记忆条目列表 | 条目:内容摘要、时间、是否含实体锚点(project/requirement/task/doc) | 分页(cursor) |
| 条目详情 | 全文、锚点实体(点击跳转)、来源会话 | 点击展开 |
| 修正 | 编辑条目内容(重写记忆) | editor+;改动记入 activity |
| 删除 | 软删单条记忆 | editor+ |
| 清空 | 清某 agent 的全部记忆 | 二次确认 |
| token 展示 | 该 agent 的蒸馏消耗概览(按 02 的成本模型) | 只读 |

权限:记忆管理页 = **editor+ 可看可改**,viewer 隐藏入口?(或 viewer 只读?)——待定,见审阅点。

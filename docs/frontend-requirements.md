## 2. 工作区级功能

### 2.1 登录与注册引导
- 账号+密码表单;失败给出明确错误(账号不存在/密码错误)
- 首用户引导:系统无账号时进入"注册为管理员"流程(仅一次)
- 成员首登设密码:admin 添加成员后,成员首次登录时强制设密码

### 2.2 项目列表
- 展示当前用户可见项目(卡片或列表),含名称、成员角色徽章
- 新建项目(工作区 admin):名称必填
- 无项目时空状态引导

### 2.3 成员管理(admin)
- 成员列表:用户名、角色(admin/member)、加入时间
- 添加成员:账号+角色(无 SMTP,账号即用户名)
- 改角色 / 移除成员
- 不可移除自己为唯一 admin 时需拦截

### 2.4 Agent 管理(admin)
- 创建 agent(输入用户名,自动生成初始凭据);删除 agent = 软删 + 全 key 吊销 + 清记忆授权,二次确认
- **API key**:仅 agent 签发;一个 agent 多 key 并存、独立吊销
- 明文 key 仅签发时展示一次;已存 key 可回看,回看需输入管理员自己密码验证
- key 列表:note、创建时间、吊销时间、已吊销态

### 2.5 全局搜索
- 工作区级常驻搜索入口(顶栏),跨项目
- 结果按域分组:需求/任务/文档(Wiki/字典/API)/记忆
- 与 MCP `search.query` 同一后端;关键词+语义混合
- 结果点击跳转到对应实体详情

### 2.6 通知
- 轻量站内通知:未读数角标、列表(时间+摘要)
- 内容:"我关注实体的变更"(创建/状态变更/评论/指派)
- 点击跳转到对应实体
- v1 无偏好系统、无邮件/推送;通知按已读/未读处理

## 3. 项目级功能

### 3.1 需求
- **列表页**(默认):卡片或表格;状态过滤(五态)、按更新时间排序
- **详情页**:
  - 标题、描述、状态徽章、创建/更新时间、创建者
  - **关联任务**面板:派生任务列表,任务完成情况与需求状态联动提示
  - **引用面板**:双向引用(derives/documents/implements/mentions),新增/删除引用
  - **评论流**:发表、删除(自己的或 owner/admin)
  - **活动流**:全部变更轨迹,actor 区分人/agent
  - **操作按钮按权限**:取消(任意非终态)、验收(验收中态 → 已完成,必填验收说明)
- 自动流转仅由后端驱动,前端只展示提示(如"全部任务完成,需求进入验收中")

### 3.2 任务
- **看板页**(默认):按状态五列(待办/实现中/验收中/已完成/已取消),卡片含标题、指派人、需求来源
- **列表页**:表格视图,可切换;筛选(状态/指派人/需求)与排序
- **详情页**(或看板侧栏):
  - 状态流转按钮按权限:认领(未指派)、开始、验收(带说明)、取消、改派
  - 派生任务显示来源需求链接;独立任务显示"独立任务"
  - 指派限制提示:已指派任务仅本人或团队 admin 可改状态/改派(前端禁用+后端兜底)
- 认领后按钮态实时更新;权限不足的按钮隐藏或禁用

### 3.3 文档三子模块
- **Wiki**:列表(标题、更新时间);阅读页渲染 Markdown;编辑页 IR 即时渲染;保存生成新版本;版本历史页(版本号、时间、回滚按钮,回滚二次确认)
- **字典**:词条列表 + 按词名查找;词条详情(释义正文);新建/编辑
- **API 定义**:列表;渲染页(名称、描述、schema);编辑页 schema 保存时后端校验,前端展示校验错误;反向引用自查入口(谁引用了这个 API 定义)
- 三类文档共用:软删(删除二次确认)→ 恢复入口(列表可见"已删除"墓碑);附件挂载;引用

### 3.4 记忆管理页(editor+,viewer 无入口)
- **过滤**:按 agent 下拉过滤;默认聚合项目记忆
- **条目列表**:记忆条目、所属 agent、锚点(指向业务实体,可跳转)
- **详情**:条目内容;操作:删除单条(透传 cognee)、修正(改内容触发 cognee update)
- **清空**:按 agent 全清,仅人类可用,二次确认
- **token 概览**:每 agent 近 7 天/30 天/累计消耗(对接 cognee usage)
- **记忆互通授权**:admin 配置 agent A 只读 agent B 的 Dataset;列表 + 添加/移除
- **立即蒸馏**:手动触发按钮(对应自动蒸馏兜底)

### 3.5 项目设置(owner)
- 项目名称修改、项目删除(二次确认,提示级联范围)
- 项目成员管理:添加成员、角色(owner/editor/viewer)、移除

## 4. 通用组件与交互需求

| 组件 | 需求 |
|---|---|
| 状态徽章 | 五态统一呈现(待办/实现中/验收中/已完成/已取消),全局同义 |
| 权限按钮 | 按角色(owner/editor/viewer/admin)显隐/禁用;后端仍兜底校验 |
| 评论流 | 评论列表 + 输入框;作者、时间;删除权限(自己的或 owner/admin) |
| 活动流 | 只读时间线:action + actor(人/agent 区分) + 摘要 |
| 引用面板 | 双向引用列表,类型枚举(derives/documents/implements/mentions);增删 |
| 附件 | 上传/下载,挂任意实体;配额提示(单项目 2GB、单文件 20MB) |
| 软删/恢复 | 删除一律二次确认;恢复入口可见;物理清理后的实体显示"已删除"墓碑 |
| 分页 | 列表统一 cursor 分页(不透明游标),滚动或"加载更多" |
| 二次确认 | 删除、取消、清空记忆、回滚版本、回看 key 等破坏性操作必弹确认 |
| 编辑器 | Markdown 即时渲染(IR)模式,所见即所得;不做双栏、不做富文本 |
| 反馈态 | 加载中(骨架屏/占位)、空状态(引导文案)、错误(可重试) |
| 表单校验 | 必填、字数上限;后端错误(permission_denied/not_found/conflict/invalid_request)映射为可读提示 |

## 5. 非功能需求

- 界面语言:中文
- 设备:桌面浏览器优先,窄屏可正常阅读(不做移动端深度适配)
- 明暗主题:支持明/暗两套(已具备变量基础),默认值与切换方式实现时定
- 前端只读数据优先乐观更新;列表刷新遵循服务端状态为准(自动流转由后端驱动)
